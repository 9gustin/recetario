## 1 · Sonnet — configuración puntual

```text
Sos el responsable de configuración del proyecto en ~/projects/recetario (WSL).

Leé CLAUDE.md, docs/execution/README.md, docs/execution/01-configuracion-sonnet.md (sección C) y docs/plan/etapa-10-notificaciones-pulido.md.

Hacé solo la configuración puntual de esta etapa (claves VAPID para Web Push), según la tabla de la sección C de docs/execution/01-configuracion-sonnet.md. No escribas código de la etapa: eso lo hace otro agente.

Reglas:
- Los pasos en consolas web los hago yo: guiame paso a paso y esperá mi confirmación.
- Nunca me pidas claves en el chat. Decime en qué archivo o panel van (.env.local, Vercel, secrets de GitHub, supabase/config.toml).
- Lo que se pueda dejar en el repo (config.toml, .env.example, docs/deploy.md) dejalo commiteado en main con el mensaje "config(etapa-10): <resumen>".
- Creá la rama etapa-10 desde main y subila: `git checkout main && git pull && git checkout -b etapa-10 && git push -u origin etapa-10`.
- Al final, verificá que la configuración funciona y decime qué quedó listo.
```
